## neues Image aus … → Container … aktualisieren {#meta-image-trigger}

<div className="block-sig" style={{ '--c': '#ad5aa1' }}>neues Image aus [1] → Container [2] aktualisieren</div>

**Stapelblock** · Typ-ID `meta_image_trigger` · gehört unter ein Deployment / StatefulSet

> OpenShift Image-Trigger: aktualisiert den Container, sobald der ImageStreamTag ein neues Image bekommt.

| # | Feld | Art | Standard | Auswahl |
| --- | --- | --- | --- | --- |
| 1 | `IST` | Text | `demo-app:latest` |  |
| 2 | `CONT` | Text | `demo-app` |  |

<details>
<summary>Erzeugtes YAML mit Standardwerten</summary>

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: demo
  annotations:
    image.openshift.io/triggers: '[{"from":{"kind":"ImageStreamTag","name":"demo-app:latest"},"fieldPath":"spec.template.spec.containers[?(@.name==\"demo-app\")].image"}]'
spec:
  replicas: 1
  selector:
    matchLabels:
      app: demo
  template:
    metadata:
      labels:
        app: demo
```

</details>
