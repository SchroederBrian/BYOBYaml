## Healthcheck … … alle … Timeout … Versuche … Startphase … {#svc-healthcheck}

<div className="block-sig" style={{ '--c': '#7a68d4' }}>Healthcheck [1] [2] alle [3] Timeout [4] Versuche [5] Startphase [6]</div>

**Stapelblock** · Typ-ID `svc_healthcheck` · gehört in einen "Service"-Block

> Shell: Befehl läuft in /bin/sh. Befehl (CMD): direkt ausgeführt, Argumente mit Leerzeichen in Anführungszeichen setzen.

| # | Feld | Art | Standard | Auswahl |
| --- | --- | --- | --- | --- |
| 1 | `MODE` | Auswahl | `Shell (CMD-SHELL)` | `Shell (CMD-SHELL)` → `CMD-SHELL`, `Befehl (CMD)` → `CMD` |
| 2 | `CMD` | Text | `curl -f http://localhost/ || exit 1` |  |
| 3 | `INT` | Text | `30s` |  |
| 4 | `TO` | Text | `5s` |  |
| 5 | `RET` | Zahl | `3` |  |
| 6 | `START` | Text | *(leer)* |  |

<details>
<summary>Erzeugtes YAML mit Standardwerten</summary>

```yaml
services:
  web:
    image: nginx:latest
    healthcheck:
      test:
        - CMD-SHELL
        - curl -f http://localhost/ || exit 1
      interval: 30s
      timeout: 5s
      retries: 3
```

</details>
