## Docker Compose

### Datenbanken

#### PostgreSQL

Service mit Volume, Healthcheck und Restart

- `Service db Image postgres:16-alpine`
  - `Variable POSTGRES_USER = app`
  - `Variable POSTGRES_PASSWORD = change-me`
  - `Variable POSTGRES_DB = app`
  - `Volume pgdata → /var/lib/postgresql/data nur lesen ☐`
  - `Healthcheck pg_isready -U app alle 10s Timeout 5s Versuche 5`
  - `Neustart unless-stopped`
- `Volume pgdata Treiber Standard`

<details>
<summary>Erzeugtes YAML</summary>

```yaml
services:
  db:
    image: postgres:16-alpine
    environment:
      POSTGRES_USER: app
      POSTGRES_PASSWORD: change-me
      POSTGRES_DB: app
    volumes:
      - pgdata:/var/lib/postgresql/data
    healthcheck:
      test:
        - CMD-SHELL
        - pg_isready -U app
      interval: 10s
      timeout: 5s
      retries: 5
    restart: unless-stopped
volumes:
  pgdata:
```

</details>

#### BuildConfig Docker + Webhook

Git → Dockerfile → ImageStream

- `BuildConfig app-build → ImageStreamTag app:latest Ablauf Serial`
- `Git Quelle https://github.com/example/app.git Branch main Unterordner `
- `Docker-Strategie Dockerfile Dockerfile`
- `Build starten bei Config-Änderung Webhook-Secret `
- `Build starten bei GitHub Push Webhook-Secret github-webhook`

<details>
<summary>Erzeugtes YAML</summary>

```yaml
apiVersion: build.openshift.io/v1
kind: BuildConfig
metadata:
  name: app-build
spec:
  runPolicy: Serial
  source:
    type: Git
    git:
      uri: https://github.com/example/app.git
      ref: main
  strategy:
    type: Docker
    dockerStrategy:
      dockerfilePath: Dockerfile
  output:
    to:
      kind: ImageStreamTag
      name: app:latest
  triggers:
    - type: ConfigChange
    - type: GitHub
      github:
        secretReference:
          name: github-webhook
```

</details>

#### BuildConfig S2I Node.js

Source-to-Image mit Builder aus openshift

- `BuildConfig app-build → ImageStreamTag app:latest Ablauf Serial`
- `Git Quelle https://github.com/example/app.git Branch main Unterordner `
- `S2I-Strategie Builder nodejs:20-ubi9 aus Namespace openshift`
- `Build starten bei Config-Änderung Webhook-Secret `
- `Build starten bei neuem Basis-Image Webhook-Secret `

<details>
<summary>Erzeugtes YAML</summary>

```yaml
apiVersion: build.openshift.io/v1
kind: BuildConfig
metadata:
  name: app-build
spec:
  runPolicy: Serial
  source:
    type: Git
    git:
      uri: https://github.com/example/app.git
      ref: main
  strategy:
    type: Source
    sourceStrategy:
      from:
        kind: ImageStreamTag
        name: nodejs:20-ubi9
        namespace: openshift
  output:
    to:
      kind: ImageStreamTag
      name: app:latest
  triggers:
    - type: ConfigChange
    - type: ImageChange
      imageChange: {}
```

</details>

#### Autoscaler CPU + RAM

2–10 Pods, ruhiges Herunterskalieren

- `Autoscaler web für Deployment web min 2 max 10`
- `Ziel CPU Auslastung 70 %`
- `Ziel RAM Auslastung 80 %`
- `herunterskalieren erst nach 300 Sekunden Ruhe`

<details>
<summary>Erzeugtes YAML</summary>

```yaml
apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
metadata:
  name: web
spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: web
  minReplicas: 2
  maxReplicas: 10
  metrics:
    - type: Resource
      resource:
        name: cpu
        target:
          type: Utilization
          averageUtilization: 70
    - type: Resource
      resource:
        name: memory
        target:
          type: Utilization
          averageUtilization: 80
  behavior:
    scaleDown:
      stabilizationWindowSeconds: 300
```

</details>
