# Tastatur & Maus

## App

| Taste | Aktion |
| --- | --- |
| <kbd>Strg</kbd>+<kbd>S</kbd> | Projekt sofort speichern; gespeichert wird ohnehin automatisch |
| <kbd>Esc</kbd> | Menü oder Dialog schließen |
| <kbd>Enter</kbd> | In Dialogen bestätigen; in der Dateiliste Umbenennen abschließen |
| Doppelklick auf Datei oder Ordner | Umbenennen (auch <kbd>F2</kbd>) |
| <kbd>Strg</kbd>+Klick / <kbd>Shift</kbd>+Klick in der Dateiliste | Mehrere Dateien auswählen / Bereich auswählen |
| <kbd>Strg</kbd>+<kbd>A</kbd> in der Dateiliste | Alle Dateien auswählen |
| <kbd>Entf</kbd> in der Dateiliste | Ausgewählte Dateien löschen (mit Rückfrage) |
| Datei auf Ordner ziehen | In den Ordner verschieben |

## Block-Fläche

| Rechtsklick auf einen Block | Rechtsklick auf die leere Fläche |
| --- | --- |
| ![Kontextmenü Block](/img/screens/kontextmenue.png) | ![Kontextmenü Fläche](/img/screens/kontextmenue-flaeche.png) |

| Taste / Geste | Aktion |
| --- | --- |
| <kbd>Strg</kbd>+<kbd>Z</kbd> / <kbd>Strg</kbd>+<kbd>Y</kbd> | Rückgängig / Wiederholen |
| <kbd>Strg</kbd>+<kbd>C</kbd> / <kbd>Strg</kbd>+<kbd>V</kbd> | Block mit allem darin **und allen Blöcken darunter** kopieren / einfügen, auch in eine andere Datei; bei einer Auswahl alle ausgewählten Blöcke |
| <kbd>Strg</kbd>+<kbd>X</kbd> | Ausschneiden (Block ab hier bzw. die Auswahl) |
| <kbd>Strg</kbd>+<kbd>D</kbd> | Auswahl duplizieren |
| <kbd>Entf</kbd> / <kbd>Rücktaste</kbd> | Gewählten Block bzw. die Auswahl löschen |
| Ziehen am Block | Block und alle darunter verschieben; ist er ausgewählt, alle ausgewählten Stapel |
| Ziehen auf leerer Fläche | Modus **Auswählen**: Rahmen aufziehen · Modus **Verschieben**: Fläche verschieben |
| <kbd>Shift</kbd>+Ziehen / <kbd>Shift</kbd>+Klick | Zur Auswahl hinzufügen / Block an- und abwählen |
| <kbd>Leertaste</kbd> oder mittlere Maustaste + Ziehen | Fläche verschieben (im Modus Auswählen) |
| <kbd>Strg</kbd>+<kbd>A</kbd> | Alle Blöcke auswählen |
| <kbd>Esc</kbd> | Auswahl aufheben |
| Mausrad | Zoomen |
| Rechtsklick auf Block | Duplizieren, Kommentar, Deaktivieren, Löschen, *Ab hier als Vorlage speichern…* |
| Rechtsklick auf Fläche | Rückgängig, Aufräumen, alle zusammenklappen / ausklappen, alle löschen |
| Block in die Palette ziehen | Löschen |
